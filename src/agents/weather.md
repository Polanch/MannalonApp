Farmer weather tool workflow:

1. Farmers open Weather from the Farmer header.
2. The tool uses the Farmer's registered farm coordinates when available.
3. If the farm has no saved map location, the tool requests browser location access.
4. Open-Meteo supplies current conditions and a seven-day forecast without an API key.
5. The dashboard displays temperature, humidity, precipitation, wind, sunrise, sunset, rain probability, and practical farm-planning guidance.

Route: `/farmer/weather`
